# 슬라임 러시 디펜스 (Slime Rush Defense)

마을로 몰려오는 슬라임 무리를 **사람 영웅 8명**으로 막아내는 3D 타워 디펜스 게임입니다.
맞을 때마다 한 단계씩 작은 슬라임으로 쪼개지는 구조라, 겹겹이 벗겨내는 손맛이 핵심이에요.

- Three.js + TypeScript + Vite, 외부 에셋 없이 모든 모델·효과음을 코드로 생성
- 맵 8개 (쉬움 → 지옥), 맵에 따라 웨이브 30개 또는 40개, 적 19종(보스 5종)
- 유닛마다 업그레이드 경로 2개 × 3단계 (한 경로만 3단계까지)
- 데스크톱(마우스·키보드)과 모바일(터치, 가로 화면 권장) 지원

> 클래식 풍선 타워 디펜스 게임들에서 영감을 받은 개인 팬 프로젝트입니다. 원작과 무관하며 원작의 이름·그래픽·사운드를 사용하지 않습니다.

## 실행

```bash
git clone https://github.com/sylee0604/slime_defense.git
cd slime_defense
npm install
npm run dev      # http://127.0.0.1:5188
npm run build    # dist/ 에 정적 파일 생성
npm run preview  # 빌드 결과 미리보기
```

## 조작

| 입력 | 동작 |
| --- | --- |
| `1` ~ `8` 또는 상점 클릭 | 유닛 선택 |
| 맵 클릭 | 배치 / 배치된 유닛 선택 |
| `Shift` + 클릭 | 연속 배치 |
| 우클릭, `Esc` | 취소 · 선택 해제 (아무것도 없으면 일시정지) |
| `Z` / `X` | 선택한 유닛의 1번 / 2번 경로 업그레이드 |
| `Tab` | 공격 대상 변경 (맨 앞 · 맨 뒤 · 강한 적 · 가까운 적) |
| `Delete` | 판매 (투자금의 70%) |
| `Space` | 웨이브 시작 (진행 중이면 배속) |
| `F` | 배속 1x → 2x → 3x |

## 맵

| 맵 | 난이도 | 웨이브 | 특징 |
| --- | --- | --- | --- |
| 초록 들판 | 쉬움 | 30 | 길고 구불구불한 입문 맵 |
| 모래 협곡 | 쉬움 | 30 | 오아시스 때문에 배치 공간이 좁음 |
| 눈꽃 마을 | 보통 | 30 | 짧은 길, 체력·물량 ×1.3 |
| 용암 화산 | 어려움 | 40 | 용암 웅덩이가 명당을 막음, 물량 ×1.3 |
| 갈림길 늪 | 매우 어려움 | 40 | 두 갈래 길이 중간에서 합류 |
| 정글 유적 | 매우 어려움 | 40 | 짧은 길, 적 속도 ×1.2 |
| 수정 동굴 | 지옥 | 40 | 서로 교차하는 두 길, 출구도 둘 |
| 마왕성 | 지옥 | 40 | 위아래에서 몰려와 성문 앞 합류, 아주 짧은 길 |

맵마다 체력·속도·물량 배수가 붙습니다. 31~40웨이브는 40웨이브 맵에만 나오고, 마지막은 마왕 슬라임이 나옵니다.

## 슬라임

빨강 → 파랑 → 초록 → 노랑 → 분홍 순으로 단단하고 빨라집니다. 게임 메뉴의 **슬라임 도감**에서 전체 목록을 볼 수 있고, 새로운 적이 처음 나오는 웨이브에는 안내가 뜹니다.

| 슬라임 | 특징 |
| --- | --- |
| 그림자 | 폭발 면역 |
| 서리 | 냉기 면역 |
| 보라 | 마법·화염 면역 |
| 번개 | 엄청 빠르고 얼지 않음 |
| 강철 | 날붙이(다트·못·부메랑) 면역 |
| 얼룩 / 무지개 | 여러 면역을 가진 상위 슬라임 |
| 갑옷 | 갑옷 1: 피해 1짜리 공격을 막음 → '갑옷 무시' 업그레이드 필요 |
| 바위 | 체력 8, 무지개 2마리로 분열 |
| 기사 (중간 보스) | 체력 60, 바위 2마리 |
| 킹 → 황제 → 타이탄 → 마왕 (보스) | 체력 200 / 700 / 2400 / 6000, 한 단계 아래 보스를 쏟아냄. 타이탄·마왕은 갑옷 보유 |

새어 나간 슬라임은 남은 단계 수만큼 생명을 깎습니다. 보스가 새면 사실상 게임 오버예요.

**갑옷 무시 업그레이드 (경로-단계):** 다트 투수 1-2, 못 발사꾼 2-3, 폭탄병 1-2, 냉동 기술자 1-3, 저격수 1-1, 부메랑 투수 1-2, 마법사 1-1

## 플레이 / 배포

**바로 플레이:** https://sylee0604.github.io/slime_defense/

### 배포 방식

저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꾸면,
`main` 에 푸시할 때마다 워크플로가 빌드해서
`https://sylee0604.github.io/slime_defense/` 에 배포합니다. (`vite.config.ts` 의 `base: './'` 덕분에 저장소 이름이 달라도 동작)

## 프로젝트 구조

```
src/
  main.ts              진입점
  game/
    Game.ts            게임 루프, 웨이브, 타워·투사체·피해 처리, 입력
    World.ts           맵(지형·길·호수·소품) 생성
    models.ts          사람 유닛·슬라임 절차적 모델
    Effects.ts         파티클·링·번개 효과
    Audio.ts           Web Audio 합성 효과음
    Path.ts            경로 샘플링
    data/              유닛·슬라임·웨이브·맵 데이터 (밸런스 조절은 여기서)
  ui/Ui.ts             HUD, 상점, 업그레이드 패널, 메뉴
tests/smoke.spec.ts    Playwright 스모크 테스트
.github/workflows/     GitHub Pages 자동 배포
```
